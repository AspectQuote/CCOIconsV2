# CCO Icons Server
Cube Collector uses this server as its source for most (like 99%) of the icons in the game. Icons can be generated on-the-fly, and unlike the old version of CCOIcons, this version is much more efficient with the icons it does have to generate.

Currently, ~50% of cubes don't have verified part (head, mouth, eye, accent) placements. This work will be continued soon.
